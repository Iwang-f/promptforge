      # 🎯 Concept Generator

      Transform a one-line product brief into **3 distinct, conversion-focused video ad concepts** — each with a different psychological angle.

      ## When to use

      - User has a DTC product and needs AI video ad ideas
      - User wants to A/B test multiple creative directions
      - User is stuck producing generic "feature-list" ads

      ## Workflow

      1. **Intake:** Ask user for:
         - Product name + 1-line description
            - Target audience (demographic + psychographic)
               - Primary conversion goal (awareness / click / purchase)
                  - Brand tone (3 adjectives)

                  2. **Generate 3 concepts**, each using a different framework:
                     - **Concept A — Problem/Agitation/Solution (PAS)**
                        - **Concept B — Aspirational Lifestyle**
                           - **Concept C — Curiosity Hook / Pattern Interrupt**

                           3. **For each concept output:**
                              - One-sentence hook (first 3 seconds)
                                 - Visual mood (3-5 descriptive words)
                                    - Emotional payoff
                                       - Recommended duration (15s / 30s / 60s)
                                          - Why this works for the target audience

                                          ## Output format

                                          **CONCEPT A: [Catchy Name]**

                                          Framework: PAS | Hook: [First-3-second hook] | Visual mood: [keywords] | Emotional payoff: [what viewer feels at end] | Duration: [15s/30s/60s] | Why it converts: [1-2 sentence rationale]

                                          [Repeat for B and C]

                                          ## Notes

                                          - Always produce 3 *genuinely different* angles — no variations of the same idea.
                                          - If user's brief is too vague, ask 1 clarifying question before generating.
                                          - Output must be ready to feed directly into the `02-script-shotlist` skill.
